A userscript to download Civitai model info as a ZIP with a presentable HTML page. If the model is later removed by Civitai or the author, you will still have the info.

------------
- Click *Model Info Saver* on the right panel on Civitai to show the download panel.

- Fetches all the useful model info, any preview media, description and *About this version* sections, comments and replies.

- You can edit *notes.js* to add personal notes. You can also add the original file name into its designated slot if you plan to rename the model file.

- You can drag a screenshot file of the model page named *screenshot.png* directly over the ZIP file if you want to archive that as well. A button to show the screenshot will appear in the HTML page.

- Works with Violentmonkey or Tampermonkey. I prefer the open source Violentmonkey.
